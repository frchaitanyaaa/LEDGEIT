# LEDGEIT

**A cryptographically verifiable chain of custody for every AI manufacturing decision.**

LEDGEIT binds *Evidence + Model + Decision + Explanation + Human Response + Timestamp* into one tamper-evident record, chains every event per production line, anchors Merkle roots on a public ledger, and lets anyone re-verify a record later.
